# Stock Cars (working title)

Classification: Internal. Personal project (Grant), not TTRO and not Autumn Leaf.

A ZX Spectrum 48K racing game: weapon trucks on a scrolling oval. You build a truck (body, wheels,
weapon, defence), race laps, and use the weapon to spin rivals. Started 16 Nov 2026 21:32 SAST from a copy of the
Breakfast Run engine (GitHub grant-cmyk/breakfastrun, commit d2f8edf).

- CONTINUE.md: where the work stands and what to do next. Read it first.
- PROJECT-LOG.md: the history and the decisions.
- docs/design/mockups/: the first-look pictures Grant chose from.
- src/, tools/, tests/, build.sh: the Breakfast Run engine as copied. It is still Breakfast Run until changed.
